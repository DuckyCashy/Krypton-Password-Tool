# ✨ Krypton Password Generator

Krypton is an open-source, decentralized, client-side cryptographic utility engineered for zero-trust environments. Designed with a premium premium "Liquid Glass" neon aesthetic, it delivers non-deterministic entropy generation entirely inside your browser.

## 🚀 Features

- **Hardware-Seeded Entropy:** Driven natively by the browser's `Web Crypto API` (CSPRNG) rather than predictable `Math.random()`.
- **Live Entropy Analysis:** Real-time evaluation engine assessing password string strength against pool variations.
- **Scramble Reveal Animation:** High-tech text matrix scramble animation upon password generation.
- **Liquid Glass Interface:** Ultra-sleek glassmorphic card layouts backing deep moving neon noise blurs.
- **Zero Data Leakage:** 100% localized script architecture. No database connections, tracking scripts, or server logging.

## 🛠️ Tech Stack

- **Core Engine:** Vanilla ECMAScript 6 Modules
- **Cryptography:** Web Crypto API (`window.crypto.getRandomValues`)
- **Styling UI:** Fluid glassmorphism tokens, layered CSS dynamic backdrops, and hardware-accelerated animations
